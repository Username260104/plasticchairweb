# 3D Website Project

This project uses Three.js.

## How to run

Since this uses ES Modules, you need a local web server to view it.

### Using Python (Pre-installed)
Run the following command in this directory:
```bash
python -m http.server
```
Then open [http://localhost:8000](http://localhost:8000) in your browser.

### Using VS Code
If you use VS Code, install the "Live Server" extension and click "Go Live" at the bottom right.
